# 🛡️ parent cantrol md - Parental Control & Child Monitoring Android App

An intelligent Android application built with **Jetpack Compose**, **Material Design 3**, and modern Android architecture for real-time parental monitoring, remote camera/audio tracking, screen time management, and child safety.

---

## 📥 How to Download APK (Android App)

### Option 1: Direct Download from GitHub Releases
1. Click on **[Releases](../../releases)** on the right side of this GitHub repository.
2. Under **Assets**, click on **`ParentControlMD.apk`** to download directly to your Android mobile.
3. Open the downloaded APK on your mobile and tap **Install**.

### Option 2: Download from GitHub Actions (CI/CD)
1. Go to the **Actions** tab in this GitHub repository.
2. Click on the latest workflow run: **"Build & Release Android APK"**.
3. Scroll down to **Artifacts** and click **`ParentControlMD-APK`** to download the signed APK.

## ✨ Key Features & Capabilities

- 📊 **Usage Report & Screen Time Tracking**: Monitor daily screen time usage with 3D isometric charts and detailed app breakdown.
- 📷 **Live Monitoring & Remote Access**:
  - **Remote Camera**: Real-time front and back camera snapshot & streaming.
  - **Screen Mirroring**: Live remote screen view of the child's device.
  - **One-Way Audio**: High-clarity ambient listening.
- 🛑 **App Blocking & Control**: Instant "Block All Apps" toggle with customizable allowed lists and app usage limits.
- 📍 **GPS Live Location & Geofencing**: Real-time map preview with safe zone radius and child avatar pin marker.
- 💬 **Bilingual Support**: Fully supported in both **English** and **Hindi** (हिंदी).
- 🎨 **Modern Material Design 3 UI**: Polished device header, online status indicator, battery tracker, and smooth Jetpack Compose animations.

---

## 🛠️ Tech Stack & Architecture

- **UI Framework**: Jetpack Compose (Material Design 3)
- **Language**: Kotlin 100%
- **Architecture**: MVVM (Model-View-ViewModel) with Kotlin Coroutines & Flows
- **Automation**: GitHub Actions CI/CD pipeline for automatic APK release building
